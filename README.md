## 🇬🇧 English

Welcome to my coding practice repository!

This is my personal space for learning, experimenting, solving problems, and improving my programming skills one step at a time.

I'm starting small, learning by doing, and trying to get a little better with every exercise and project. Things here may change, evolve, or get rewritten as I learn new concepts and discover better ways to do things.

### 🎯 What is this repository for?

- Practicing programming concepts and problem-solving.
- Building small exercises and projects to put what I learn into practice.
- Exploring different tools, libraries, and technologies.
- Tracking my progress and learning from my mistakes.
- Building a solid foundation for future projects and freelance work.

### 📁 How is it organized?

Each folder is intended to contain a separate exercise or small project. The contents and organization may change over time as my learning journey continues.

### 🚀 Running a project

Each project may have its own setup and requirements.

For projects that use npm, open a terminal in the relevant project folder and install the dependencies:

```bash
npm install
```

If it's a Vite project, start the development server with:

```bash
npm run dev
```

Follow any additional instructions provided by the individual project when needed.

### 🌱 A work in progress

This repository is a work in progress, just like my learning journey.

Some exercises may be simple, incomplete, or experimental. That's part of the process. The goal isn't to get everything perfect from day one, but to keep learning, practicing, and moving forward.

## 🇮🇷 فارسی

به مخزن تمرین برنامه‌نویسی من خوش اومدی!

این مخزن فضای شخصی منه برای یادگیری، آزمایش ایده‌ها، حل مسئله و بهتر شدن در برنامه‌نویسی؛ قدم‌به‌قدم و با تمرین.

یادگیری رو از کارهای کوچک شروع می‌کنم، با انجام دادن یاد می‌گیرم و سعی می‌کنم با هر تمرین و پروژه کمی بهتر بشم. با یاد گرفتن مفاهیم جدید و پیدا کردن راه‌های بهتر، ممکنه بعضی قسمت‌ها تغییر کنن یا از نو نوشته بشن.

### 🎯 هدف این مخزن چیه؟

- تمرین مفاهیم برنامه‌نویسی و حل مسئله.
- ساخت تمرین‌ها و پروژه‌های کوچیک برای استفاده عملی از چیزهایی که یاد می‌گیرم.
- آشنایی و کار با ابزارها، کتابخانه‌ها و فناوری‌های مختلف.
- ثبت روند پیشرفت و یاد گرفتن از اشتباهات.
- ساختن پایه‌ای محکم برای پروژه‌های آینده و فعالیت در حوزه فریلنسری.

### 📁 پوشه‌ها چطور سازمان‌دهی می‌شن؟

قرار است هر پوشه شامل یک تمرین یا پروژه کوچک و مستقل باشد. محتوا و ساختار پوشه‌ها ممکن است با ادامه مسیر یادگیری تغییر کند.

### 🚀 اجرای پروژه‌ها

هر پروژه ممکن است روش راه‌اندازی و نیازمندی‌های مخصوص خودش را داشته باشد.

برای پروژه‌هایی که از npm استفاده می‌کنند، ترمینال را در پوشه همان پروژه باز کن و وابستگی‌ها را نصب کن:

```bash
npm install
```

اگر پروژه با Vite ساخته شده باشد، سرور توسعه را با دستور زیر اجرا کن:

```bash
npm run dev
```

اگر پروژه به مراحل یا تنظیمات دیگری نیاز داشته باشد، می‌توانی دستورالعمل‌های مخصوص همان پروژه را دنبال کنی.

### 🌱 این مسیر هنوز ادامه داره

این مخزن هم مثل مسیر یادگیری من، همیشه در حال تغییره.

ممکنه بعضی تمرین‌ها ساده، ناقص یا صرفاً آزمایشی باشن؛ این هم بخشی از فرایند یادگیریه. هدف این نیست که از روز اول همه‌چیز بی‌نقص باشه، بلکه اینه که به یادگیری، تمرین و پیشرفت ادامه بدم.
